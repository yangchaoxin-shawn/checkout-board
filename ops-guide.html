项目简介
大客户牵引部团队每日打卡工具。前后端分离： - frontend/ → HTML/CSS/JS 静态文件（你放到外网 nginx 里托管） - backend/ → Python API 服务（Docker 容器，纯 API）

技术栈： Python 后端 + SQLite，Docker 打包。本包不带 nginx，由你外网统一配置。

项目结构

打卡小程序/ ├── frontend/ 前端包：静态文件（你放 nginx 里） ├── backend/ 后端包：纯 API │ ├── api.py / dev.py / main.py │ └── deploy/Dockerfile ├── deploy/ 辅助脚本（start/stop/logs） ├── docker-compose.yml 单服务编排（backend） ├── .env.example → .env（配密码 + 端口） ├── DEPLOY.md 部署文档 ├── ops-guide.html 运维部署指引（本文件） └── user-guide.html 用户操作手册

架构说明

你的外网 nginx ├── /api/* ──→ 反向代理 → 后端容器（:8080） └── / （静态文件） ──→ serve → frontend/ 目录

你的 nginx 中配置 /api/ 反向代理到 127.0.0.1:8080，其余请求直接 serve frontend/

前置要求

组件最低版本
LinuxUbuntu 20.04+ / CentOS 7+
Docker Engine24.0+
Docker Composev2.20+

部署流程

1
启动后端容器
docker compose up -d
.env 已预填默认密码 365，可直接启动。如需改密码编辑 .env：
vim .env # 改 CHECKIN_PASSWORD=xxx
docker compose up -d
验证：
curl http://localhost:8080/api/health
返回 {"status":"ok","db":"sqlite"...}
2
配置你的外网 nginx ① 将 frontend/ 目录放入你的 nginx 静态目录
cp -r frontend/ /你的nginx目录/
② 配反向代理，将 /api/* 请求转发到后端
location /api/ { proxy_pass http://127.0.0.1:8080; }
③ 编辑 frontend/config.js，将 serverUrl 设为后端 API 地址
serverUrl: 'https://你的域名' # 不加 /api

日常运维

./deploy/start.sh # 启动 / 重启 ./deploy/stop.sh # 停止（数据保留） ./deploy/logs.sh # 查看日志

备份数据

sqlite3 data/checkin.db ".backup /backup/checkin_$(date +%Y%m%d).db"

升级版本

docker compose up -d --build

常见问题

Q：端口被占用？
→ 修改 .env 中 API_PORT，换一个可用端口。

Q：密码忘了？
→ 查看 .env 中的 CHECKIN_PASSWORD。

Q：导出数据？
→ 浏览器进页面点 ⬇️ 按钮，或访问 /api/export-excel?password=xxx
